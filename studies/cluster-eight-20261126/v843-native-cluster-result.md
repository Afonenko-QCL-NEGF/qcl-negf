# Dupont V843. Отказ статической проверки в восьми кластерных заданиях

26 ноября 2026 года все восемь заданий нативной серии V843 вернули `failed` при
проверке базиса PzP. Для каждого задания записано `completed_iterations = 0`.
Ток, пространственная плотность и история невязок остались неизмеренными.
Радиальная и угловая сходимость в этой попытке не оценены.

## Причина отказа и отдельная диагностика

`DupontDevice.prepare` собирает `NEGFProblem` и прерывает запуск, если
`validate_problem` возвращает `passed=false`. Для каждой комбинации
`translation`, `translation_nearest` и `translation_two_pairs` составили
около 0,162285. Пороги Core равны 0,1 для первых двух метрик и 0,005 для
третьей в трёхпериодном базисе. Все три превышения присутствуют в
сохранённых TOML. Метрики берут максимум |Δz − Lₚ|/Lₚ для трёх наборов соседних центров. Равенство максимумов не характеризует каждое межцентровое расстояние. [Метрики базиса](https://github.com/Afonenko-QCL-NEGF/QCLNEGF.jl/blob/c2f45cae21c3e2e4257805ea9c30f9c1d80a7515/src/numerics/reference/basis.jl#L179-L204) · [Подготовка задачи](https://github.com/Afonenko-QCL-NEGF/qcl-negf/blob/a44f83e41ab53f4dcb32a232b833e134070f60fc/studies/fath-v843/controls/v843-input/dupont/dupont_device.jl#L141-L150) ·
[Критерии Core](https://github.com/Afonenko-QCL-NEGF/QCLNEGF.jl/blob/c2f45cae21c3e2e4257805ea9c30f9c1d80a7515/src/numerics/reference/validation.jl#L452-L474).

Первым в сообщении отчёта записан взвешенный дефект сопряжённости
противоположных энергетических сдвигов. Он равен 0,0328798 при 12,5 кВ/см
и 0,0331679 при 21 кВ/см. Это безразмерная величина для пары матриц с
весами энергетической квадратуры. Core берёт максимум по сдвигу поля и
LO-сдвигу. Для `nodal_linear` Core выводит конечный дефект как диагностику
и исключает его из проверок, меняющих `passed`.
[Нормировка](https://github.com/Afonenko-QCL-NEGF/QCLNEGF.jl/blob/c2f45cae21c3e2e4257805ea9c30f9c1d80a7515/src/numerics/reference/validation.jl#L154-L170) ·
[Агрегация сдвигов](https://github.com/Afonenko-QCL-NEGF/QCLNEGF.jl/blob/c2f45cae21c3e2e4257805ea9c30f9c1d80a7515/src/numerics/reference/validation.jl#L409-L425) ·
[Обработка диагностики](https://github.com/Afonenko-QCL-NEGF/QCLNEGF.jl/blob/c2f45cae21c3e2e4257805ea9c30f9c1d80a7515/src/numerics/reference/validation.jl#L452-L474).

[SHA-256 архива](evidence/v843-native-20261126/SHA256SUMS) связывает сводку с
восемью исходными TOML. Для воспроизведения сборки достаточно запустить
`collect_v843.py` из копии каталога свидетельств с его `cluster.dag` и
`results/`. Это проверка сводки по готовым данным без SCBA.

| Утверждение | Свидетельство | Ограничение | Решение |
| --- | --- | --- | --- |
| Статическая проверка PzP прервала все восемь запусков | Три превышения порогов Core и ноль итераций в каждом TOML | Записи не локализуют происхождение дефекта внутри построения базиса | Дополнительно измерить статические метрики базиса |

| Сходимость по K и числу углов осталась открытой | В сводке отсутствуют терминальные токи, плотности и невязки | Отказ произошёл до первой карты | Данных недостаточно |
