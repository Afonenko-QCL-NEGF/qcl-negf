# Dupont V843. Базис, операторы и условный транспорт

**Итог 27 ноября 2026 года.** Все восемь независимых направлений вернули данные. SELECT отклонил ранги 7 и 9 по статическим порогам, а ранги 6, 8 и 11 по сверке с рис. 1. До проверки подтверждения при расширении окна кандидаты не дошли. Пилот и четыре варианта SCBA пропущены. Ток и плотность не измерены.

На семи модах расширение окна с 7 до 11 периодов увеличило максимум ошибки трансляции с 0,162285 до 0,172126 периода. Для других рангов центральные ошибки уменьшились. У ранга 7 худшей осталась центральная пара для моды 1. Данные не устанавливают единственную причину дефекта.

Планировщик зафиксировал 16 завершённых узлов графа, включая условные пропуски, и отказ финального сборщика. Сборщик падал при обработке целочисленных ключей JSON. Сводка и учёт CPU восстановлены из имеющихся выходов и истории очереди. Связь с исходным пакетом фиксируют [исходные хеши](source-SHA256SUMS). В Git сохранены компактные численные свидетельства, а полные профили и фазовые массивы доступны на узле подачи. [Сводка](summary.json) · [Манифест публикации](SHA256SUMS).

## Учёт CPU

За 11 исполнений HTCondor зарегистрировал 487 CPU-секунд, или 0,1353 CPU-часа. При запуске первые семь задач заняли слоты на 208 CPU. Это число отражает выделение. Измеренная доля выделенного времени по рабочим узлам составила 1,98–6,54%.

На Linux запросы SELECT и SHIFT составляли 1 и 9 CPU соответственно. Julia использовала 1 и 9 потоков. События завершения HTCondor указывают 28 CPU в столбце Allocated для каждого задания. [Выписка планировщика](scheduler-evidence.json). Эти поля сохранены отдельно в [сводке](summary.json). Показатели не дают разбиения времени CPU по численным фазам.

CPU-часы = (RemoteUserCpu + RemoteSysCpu) / 3600. Доля выделения = CPU-секунды / (CPU × RemoteWallClockTime). Доля исполнения использует ActivationExecutionDuration при наличии. Для узла учитываются атрибутируемые однократные исполнения. Подготовка, вычисление, передача и ожидание различаются только при наличии соответствующего измерения.
