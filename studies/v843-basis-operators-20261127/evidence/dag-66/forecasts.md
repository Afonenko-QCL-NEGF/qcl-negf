# Dupont V843. Прогнозы до кластерных измерений

Научная спецификация закреплена в [задании](../../Agents.md) ревизии
`7202e8c5768fab4e12c0dadd66581bf3fe3ce6b3`. Матрица направлений и зависимостей
доступна в [машиночитаемом виде](../../experiment-matrix.json). Численные допуски Core
сохраняются на ревизии `c2f45cae21c3e2e4257805ea9c30f9c1d80a7515`.

| Направление | Прогноз | Различающее свидетельство |
| --- | --- | --- |
| B7 | Семь мод воспроизведут максимальную ошибку центров 0,162285 периода | Окно 7 периодов, 144 узла на период, сравнение до опубликованного округления |
| B9 | При влиянии края центральные ошибки уменьшатся при фиксированном ранге | Отдельные центральные и граничные пары, общая область и удержанная норма |
| B11 | Если ошибка связана с границей окна, центральные пары продолжат улучшаться. Если меняется назначение мод, близкие проекторы могут оставаться устойчивыми | Сопоставление тех же рангов и физических координат, сингулярные числа близких групп |
| BLOCH | Минимальный прямой зазор 7–8 может зависеть от фазы и требовать сгущения | 65 исходных фаз, две сетки z. Устойчивость после двух уточнений с изменением ≤0,01 мэВ и соседним шагом ≤π/1024 |
| IMP17 и IMP33 | Относительная ошибка диагональной пары при 32 углах может частично исчезнуть при суммировании колец | Два замороженных тестовых поля, раздельные классы пар и устойчивость адаптивного эталона |
| LO | Угловой вклад и продольная квадратура дадут разные поправки | Точное угловое среднее при фиксированной сетке qz, затем уточнение только qz |
| SHIFT | На E239 узловая схема воспроизведёт два архивных максимума. Конечно-объёмная пара обеспечит взвешенную сопряжённость с точностью округления | Абсолютный допуск воспроизведения 5×10⁻¹⁴. Структурный допуск конечно-объёмной пары 10⁻¹⁴. Внутренность и граница проверяются раздельно |
| PILOT и транспорт | Влияние 32→128 углов может пережить смену K, знак изменения тока открыт | Только прошедший SELECT базис. Пилотная полная карта, затем сравнение четырёх траекторий по невязкам и наблюдаемому дрейфу |

SELECT требует воспроизведения опубликованного контроля B7. Для SELECT исходные пороги равны 0,1 для `translation` и `translation_nearest`
и 0,005 для `translation_two_pairs`. Назначение литературы требует согласия
независимых перестановок по форме и энергии при единой пространственной
привязке и едином нуле энергии. Минимальный зазор между кандидатами по оценке
формы 0,02 и по энергетической RMS 3 мэВ. RMS победителя ≤5 мэВ. Косинус
видимой формы ≥0,8, для обрезанного профиля e ≥0,75. При одинаковом ранге
соседние допущенные окна подтверждают результат при максимальном отличии
относительных энергий ≤3 мэВ и косинусах соответствующих плотностей ≥0,95.
Среди подтверждённых кандидатов выбирается наименьший ранг и наибольшее
подтвердившееся окно.

Примесная адаптивная сверка использует два допуска 10⁻⁷ и 10⁻⁹ на одну
и ту же нормировку. Два тестовых поля определены в задании. Для SHIFT
центры пиков 175 и 980 мэВ, ширина 20 мэВ. На всех трёх сетках сохраняются
одно окно и те же физические функции.
