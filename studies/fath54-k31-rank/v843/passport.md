# Dupont V843. Вход для диагностической точки

## Рабочая точка и модель

21 кВ/см соответствуют 75,936 мВ на период 36,16 нм. Транспорт тёмный. Температуры решётки и LO-бата 50 К. Ось +z направлена вниз по потенциальной энергии электрона. Структура содержит четыре барьера Al₀․₂₅Ga₀․₇₅As и четыре ямы GaAs. От инжекционного барьера толщины составляют **4,40** / 6,25 / **1,09** / 6,65 / **2,28** / 8,48 / **0,91** / 6,10 нм. Доноры Si сосредоточены у центра первого барьера, z = 2,20 нм. Целевой листовой заряд 3,25×10¹⁰ см⁻². Используются CBO 217,5 мэВ, массы 0,067 m₀ и 0,08775 m₀, LO 36,7 мэВ, пять каналов рассеяния. Основная задача фиксирует Uₕ = 0. [Опубликованный паспорт](https://github.com/Afonenko-QCL-NEGF/qcl-negf/blob/f02b3469423545d380fe6474ed4301846100d15c/studies/fath-v843/v843-passport.md)

У опубликованного Dupont NEGF используются разложение Ванье, представительные передачи импульса и приближение среднего поля для e–e. В запечатанном входе решателя есть явная радиальная мера, собственное термодинамическое экранирование примесей и корреляция шероховатости с RMS 0,2 нм и длиной 10 нм. Форма коррелятора для рис. 9 Dupont отдельно не установлена. Для Jonasson DM50 указан феноменологический LET с α = 0,1. Отдельный IFR там отсутствует. LO-экранирование в локальной модели использует сравнимый дебаевский масштаб, однако для примесей замыкания различаются. Сравнение с измерением дополнительно ограничено импульсной температурой решётки. 10 К обозначают температуру теплоотвода. [Паспорт столкновений и оцифровки](https://github.com/Afonenko-QCL-NEGF/qcl-negf/blob/f02b3469423545d380fe6474ed4301846100d15c/studies/fath-v843/v843-passport.md#физическая-модель)

## Запечатанный вход и выбор проверки

Вход `linked-input-q28-f21-e239-cont` принадлежит траектории при E239 K5, Q28, девяти периодах и 11 модах на период. Собственные W, Q, 145 сечений со швами, меры, параметры электростатики и столкновений совпадают во всех сравниваемых вариантах. Выбрана та стадия архива, которая служила входом опубликованного продолжения. Перед диагностикой новый разгон не применяется.

- `mixing` использует общую исходную карту до ветвления. Каждый из двух вариантов выполняет четыре следующие свежие карты с долей образа 0,35 или 1,0. Свежие rK и rΣ записываются до смешивания. Для конечных профилей обе невязки должны быть в отношении до 1,25. При большем отношении приводятся сами невязки, изменение метода на общей ветви и достигнутые границы. Сопоставление профилей проводится на одних физических сечениях с отдельной оценкой расхождения штатной квадратуры и GL20.
- `unitary` заменяет W и Q внутри собственных фиксированных подпространств V843. Геометрия, H, причинные якоря и исходный пакет представлены в согласованных координатах. Источник новой карты возвращается в первоначальный Q. Сверяются взвешенные нормы L/G отдельно для всех каналов, выборочные причинные R/L/G, полости и ток по сечениям. Независимый GL20 восстанавливает полный J(z), центрированную форму и e/u в каждой руке. Одна свежая карта на представление измеряет ковариантность на общем входе.

Полная стационарность требует трёх последовательных свежих карт с rK, rΣ, |λ−1| < 10⁻⁸, спектральным дефектом < 10⁻³ и отклонением J не выше max(1 А/см², 1% |среднего J|). Для оценки совпадения профилей с опубликованными кривыми доступны только значения среднего тока. Публикации дают ориентиры по заселённостям для DM50.

## Локальный запуск

Драйвер использует Julia 1.13.4, научный checkout приложения `08e90bc605f0662f1b5559f4c0f0c5a5655ed691` и Core `c2f45cae21c3e2e4257805ea9c30f9c1d80a7515`. Из каталога подготовки запускается один выбранный вариант после Fath. Каталог вывода должен быть новым.

```bash
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 JULIA_PKG_PRECOMPILE_AUTO=0
export FATH_APP
mkdir -p "$OUT"
cd "$FATH_APP"
/usr/bin/time -v -o "$OUT/resources.txt" julia --compiled-modules=existing \
  --startup-file=no --project=runner --threads=5,0 --gcthreads=1,0 --heap-size-hint=10G \
  "$PUBLISHED_STUDIES/fath54-k31-rank/v843/v843_diagnostic.jl" "$PUBLISHED_STUDIES" \
  "$V843_ARCHIVE" mixing 5 "$OUT/trajectory.jsonl" 4 > "$OUT/run.log" 2>&1
```

Для унитарного контроля берётся новый каталог вывода, аргумент `mixing` заменяется на `unitary`, а конечный аргумент `4` опускается. Команда запускает локальный CLI из Julia-проекта `runner/`, пять рабочих потоков и однопоточные BLAS и GC. Полные поля существуют только в RAM. Записываются JSONL, журнал и квитанция ресурсов. Путь `V843_ARCHIVE` задаёт запечатанный вход, `PUBLISHED_STUDIES` — каталог `studies/` этой публикации.

Для MyST уже доступны `QP_V843_21`, `QE_V843_GRID_INPUT_21`, `QE_V843_PUBLISHED`, `QE_V843_FIG1` и `QR_V843_21_E239K5`. Новый опыт указывает общим входом ранний архив `QE_V843_GRID_INPUT_21`. Результат карты 48 остаётся отдельным свидетельством `QR_V843_21_E239K5`. Фактор смешивания — `QPAM_MIX`. Для унитарного контроля фактором служит представление фиксированного подпространства.
