# Статический спектр Dupont V843 при 21 кВ/см

`b7.yaml` фиксирует семь периодов окна H, семь мод на период при локализации
PzP и 144 узла в центральной ячейке. Геометрия взята из опубликованного
[паспорта V843](../fath-v843/controls/v843-input/dupont/device.toml). Период
36,16 нм, напряжение 75,936 мВ. Операция рассматривает k = 0 и нулевой Хартри.
Геометрия доноров здесь не влияет на спектр. Расчёт транспорта требует
самостоятельного входа с распределением доноров и рассеянием из опыта.

Аналитическое ожидание для выходного базиса — `W† M W = I`, где диагональ
`M` содержит приведённые в результате веса ячеек в нм. Для межузлового
сравнения заранее установлены максимальная разность энергий 10⁻¹⁰ эВ и
спектральная норма разности проекторов 10⁻⁸. Это инженерные допуски для
переноса одного и того же входа между платформами. Подмена координаты или
веса должна давать технический отказ. Исторический кандидат B7/ранг 7 при
этих размерах имеет относительную ошибку трансляции 0,162285 и не проходит
статическую проверку. [Свидетельство B7](https://github.com/Afonenko-QCL-NEGF/qcl-negf/blob/6002cdad8493bc2dfc97abfc60dfaeb856d48269/studies/v843-basis-operators-20261127/evidence/dag-66/results/B7.json)

```sh
runner/bin/qcl-negf plan studies/v843-spectrum/b7.yaml --max-runs 1 > b7.json
runner/bin/qcl-negf run-plan b7.json v843-b7-output
julia --project=runner studies/v843-spectrum/check-plan.jl
```

Именованный результат `cell_spectrum` находится в диагностическом артефакте.
Независимый читатель сверяет его с квитанцией, восстанавливает ортонормированные
столбцы `U = orth(M½W)` и сравнивает `U U†` и энергии. На вход подаются
каталоги `artifacts` двух соответствующих попыток.

```sh
python -m qcl_negf_results.spectrum LEFT RIGHT --energy-atol-ev 1e-10 --projector-atol 1e-8
```

`reproducible` относится к сравнению двух результатов. Допуск оператора
записан отдельно в `operator_verdicts`. Полный проектор инвариантен к
поворотам столбцов внутри сравниваемого подпространства. Для сопоставления
профилей отдельных уровней нужна проверка назначения этих уровней.

Исторический набор DAG 66 можно проверить без запуска решателя. Сборщик
прочитает именованные результаты по описи и воспроизведёт статусы SELECT,
пять пропусков и два Bloch-зазора. [Архив результатов](https://github.com/Afonenko-QCL-NEGF/qcl-negf/tree/6002cdad8493bc2dfc97abfc60dfaeb856d48269/studies/v843-basis-operators-20261127/evidence/dag-66)

```sh
python studies/v843-spectrum/collect-dag66.py PATH_TO_DAG_66 > dag66.json
```

## Свидетельства

На `qcl-condor` и `qcl-win-1` штатный Pkg подготовил отдельные чистые depots.
Попытки HTCondor 80.0 и 82.0 выполнили один и тот же файл плана. Julia 1.13.4,
два потока Julia и один поток OpenBLAS на каждом узле. Максимальная ошибка
энергий составила 1,22×10⁻¹⁵ эВ, норма разности проекторов — 1,54×10⁻¹⁴.
Оба результата вернули ошибку трансляции около 0,1622847595 при порогах
0,1, 0,1 и 0,005. [Квитанции и сравнение](evidence/cluster-static.json)

HTCondor вернул имена вложенных Windows-файлов с обратными косыми чертами.
Для независимого чтения разделители восстановлены в отдельной копии и
повторно проверены хеши. Дерево файлов Core в Ubuntu совпало с Git tree
кандидата. Дерево, вычисленное Pkg на Windows, совпало с деревом этого же
набора файлов после установки бита исполнения для всех обычных файлов на
Linux. Байты плана совпали. Временная установка использовала Pkg develop
для этой пары коммитов.

План с изменённым напряжением и исходным fingerprint завершился кодом 2
и сообщением `frozen scientific plan fingerprint mismatch`. Выхода серии нет.
Первичная подача 79.0/79.1 не разместилась и была заменена после проверки
условий. Попытка 81.0 завершилась без спектрального файла. Для 82.0 обёртка
проверяла запуск дочернего процесса Julia и наличие файла результата.

На кандидате с планом v3 один и тот же B7 выполнили Ubuntu (`87.0`)
и Windows (`86.0`). Максимальная разность энергий составила
`1,22×10⁻¹⁵ эВ`, спектральная норма разности проекторов — `1,54×10⁻¹⁴`.
Причины отказа операторной проверки совпали. На каждом узле прошли все
118 проверок checkpoint, в том числе сравнение возобновлённой траектории
с непрерывной и изоляция непубликованного сегмента истории. Для Linux
попытка `85.0` закончилась на подготовке checkpoint: 4 ГиБ не хватило для
процесса и штатного резерва. `87.0` использовала 8 ГиБ и тот же план.
Julia 1.13.4 на каждом узле работала в собственном depot с Core,
подключённым через Pkg develop. [Квитанция рабочего кандидата](evidence/cluster-experiment-contract-v3.json)

Исторический W11 требует `spec.toml`, `H.bin` и `W.bin` с SHA-256 из задания.
Исторический F13 требует `spec.toml`, packed seed, геометрию, вход карты 48
после 47 обновлений и свежий образ. В компактном отчёте F13 зафиксированы
145 сечений, rK = 0,0125791861 и rΣ = 0,0098007943. Вывод о нестационарности
относится к этому исходному опыту. Архивные массивы на проверенных путях
не найдены, поэтому новые вычисления по W11 и F13 остаются открытыми.
Опубликованный драйвер Bosco требует закреплённый `causal_operator.jl` и
согласованный вход старой реализации для парного шага.
[Исходный протокол F13](https://github.com/Afonenko-QCL-NEGF/qcl-negf/blob/d76b588c1af2ef5d3a4b09b67d0094a9a809db11/studies/fath54-common-q/evidence/fath-input-review.md)
[Паспорт Bosco](https://github.com/Afonenko-QCL-NEGF/qcl-negf/blob/d76b588c1af2ef5d3a4b09b67d0094a9a809db11/studies/fath54-common-q/bosco-passport.md)

## Воспроизведение без исходных массивов

Новая матрица использует `b7.yaml` как исходную физическую конфигурацию.
Изменяемые параметры ограничены числом периодов H (7, 9, 11) и числом
центральных мод W (6, 7, 8, 9, 11). Все 15 точек остаются независимыми.
В потребителе SELECT правило и контрольная сумма оцифровки берутся из
[admission.toml](admission.toml). На видимом интервале каждой роли интеграл
косинуса плотностей вычисляется по трапециям на координатах рисунка.
Используются один общий сдвиг z на сетке от −36,16 до 0 нм и один сдвиг
энергии для четырёх ролей. Допуск в мэВ применяется к RMS после этого
сдвига. Пространственная плотность модели измеряется в нм⁻¹, косинус и
относительные ошибки трансляции безразмерны. При нулевой удержанной
плотности оценка косинуса равна нулю.

С подготовленным Julia-проектом Runner и установленным Python-пакетом
`analysis`:

```sh
julia --project=runner studies/v843-spectrum/prepare-campaign.jl v843-matrix.json
runner/bin/qcl-negf run-plan v843-matrix.json v843-results
python studies/v843-spectrum/campaign.py v843-matrix.json v843-results > v843-selection.json
```

SELECT проверяет независимый экземпляр исходного плана, идентификаторы
родительской точки и операции, именованный выход `cell_spectrum` и его
контрольную сумму. Сравнение соседних окон допускает только один и тот же
ранг. Научный отказ и техническая ошибка дают отдельные результаты.
Синтетический тест проходит положительный маршрут до PILOT, затем
проверяет пропуск зависимых ветвей после отказа PILOT и отдельно проверяет
технический сбой и заменённого родителя. Синтетический тест не измеряет
транспорт V843.

```sh
python studies/v843-spectrum/test_campaign.py
V843_DAG_66=PATH_TO_DAG_66 python studies/v843-spectrum/test_campaign.py
```

Во второй форме тест повторно применяет критерии к опубликованным метрикам
DAG 66. Архив хранит числа сравнения с рисунком. Расчёт профилей из самой
геометрии проходит отдельно через `prepare-campaign.jl` и `campaign.py`.

Контроль областей начинает с одной и той же сгенерированной пары H/W для
двух операций. При первой решается полное окно и показывается один
период с исходной нормировкой. При второй ограничиваются и H, и W, а
диагонализация повторяется с нормировкой на одном периоде. В обоих случаях
полевой потенциал равен −F(z−z₀), Хартри равен нулю, k = 0. `b11-pzp`
использует окно из 11 периодов. `w11-wannier-proxy` использует девять
периодов и свежепостроенные функции Ванье по опубликованной геометрии.
У исторического W11 девять периодов, 11 мод на период и 145 сечений.
Побайтовая идентификация с архивными H и W остаётся открытой.
[Исторический паспорт](https://github.com/Afonenko-QCL-NEGF/qcl-negf/blob/d76b588c1af2ef5d3a4b09b67d0094a9a809db11/studies/fath54-k31-rank/v843/passport.md)

```sh
julia --project=runner studies/v843-spectrum/domain-control.jl v843-matrix.json b11-pzp b11-domains.toml
python studies/v843-spectrum/compare-domains.py b11-domains.toml
julia --project=runner studies/v843-spectrum/domain-control.jl v843-matrix.json w11-wannier-proxy w11-proxy.toml
python studies/v843-spectrum/compare-domains.py w11-proxy.toml
```

На свежем входе Ванье RMS при обрезании отображения составила 1,796261 мэВ.
После ограничения H и W она составила 11,419264 мэВ. Назначение по форме
поменяло местами u и l. Назначение по относительным энергиям сохранилось.
В приближении Ванье эти числа воспроизводят смену вывода по порогу и
назначениям, установленные для исторического W11. Независимый пересчёт
архивного компактного результата из опубликованных энергий и четырёх
назначений даёт 1,789550 мэВ. Для второго архивного RMS 11,193945 мэВ
используется зафиксированное в задании значение. Полный архивный контроль
ожидает исходных массивов. [Свежие данные Ванье](evidence/initial-w11-wannier-proxy.json)

С исходных конфигураций также повторены диагностические BLOCH, SHIFT, IMP17,
IMP33, LO17 и LO33 закреплённым научным драйвером `72fcca8`. Прямой минимум
зазора между седьмым и восьмым уровнями Блоха при нулевом поле дал
17,978450 мэВ на 144 узлах и 16,578595 мэВ на 288. Оба минимума стабильны
по критерию шага фазы. В проверке SHIFT воспроизведены обе исходные пробы
E239 и взвешенная сопряжённость конечно-объёмной пары. Опубликованные ошибки
IMP и LO сравниваются для тех же полей, норм и мер. Эти задачи измеряют
действие операторов на фиксированных входах. [Свежие численные метрики](evidence/initial-operator-controls.json) · [Закреплённый драйвер](https://github.com/Afonenko-QCL-NEGF/qcl-negf/tree/72fcca8cb10e6867651ea22d7260dc2b50cc3b44/studies/v843-basis-operators-20261127)

Для отдельного контроля B11 PzP RMS двух операций равна 1,185555 и
11,818730 мэВ соответственно. Второе значение соответствует спектру
SELECT этого кандидата. Ограниченный solve согласовался с центральным
решателем Core по всем 11 уровням в пределах 5,93×10⁻¹⁴ эВ при допуске
10⁻¹⁰ эВ. [Контроль двух областей B11](evidence/initial-b11-domains.json)

Все 15 точек выполнены через Runner и прочитаны независимо в Python.
Сравнение с заново исполненным закреплённым драйвером при общей сетке,
весах и нуле энергии дало максимальное отличие 6,66×10⁻¹⁶ эВ по уровням и
7,94×10⁻¹⁶ по спектральной норме разности проекторов. У рангов 7 и 9 во
всех окнах статический отказ. Ранги 6, 8 и 11 отклонены по сверке с
рисунком. Причины соответствуют опубликованному DAG 66. SELECT пропустил
PILOT и четыре транспортные ветви. Ток не измерялся. Изменённый выход и
подмена родителя другим корректным выходом вернули отдельные технические
ошибки. Этот расчёт сделан на одном узле. [План, числа и вердикты](evidence/initial-campaign.json)
