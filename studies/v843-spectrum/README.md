# Статический спектр Dupont V843 при 21 кВ/см

`b7.yaml` фиксирует семь периодов окна H, семь мод на период при локализации
PzP и 144 узла в центральной ячейке. Геометрия взята из опубликованного
[паспорта V843](../fath-v843/controls/v843-input/dupont/device.toml). Период
36,16 нм, напряжение 75,936 мВ. Операция рассматривает k = 0 и нулевой Хартри.
Геометрия доноров здесь не влияет на спектр. Расчёт транспорта требует
самостоятельного входа с распределением доноров и рассеянием из опыта.

Аналитическое ожидание для выходного базиса — `W† M W = I`, где диагональ
`M` содержит приведённые в результате веса ячеек в нм. Для межузлового
сравнения заранее установлены максимальная разность энергий 10⁻¹⁰ эВ и
спектральная норма разности проекторов 10⁻⁸. Это инженерные допуски для
переноса одного и того же входа между платформами. Подмена координаты или
веса должна давать технический отказ. Исторический кандидат B7/ранг 7 при
этих размерах имеет относительную ошибку трансляции 0,162285 и не проходит
статическую проверку. [Свидетельство B7](https://github.com/Afonenko-QCL-NEGF/qcl-negf/blob/6002cdad8493bc2dfc97abfc60dfaeb856d48269/studies/v843-basis-operators-20261127/evidence/dag-66/results/B7.json)

```sh
runner/bin/qcl-negf plan studies/v843-spectrum/b7.yaml --max-runs 1 > b7.json
runner/bin/qcl-negf run-plan b7.json v843-b7-output
julia --project=runner studies/v843-spectrum/check-plan.jl
```

Именованный результат `cell_spectrum` находится в диагностическом артефакте.
Независимый читатель сверяет его с квитанцией, восстанавливает ортонормированные
столбцы `U = orth(M½W)` и сравнивает `U U†` и энергии. На вход подаются
каталоги `artifacts` двух соответствующих попыток.

```sh
python -m qcl_negf_results.spectrum LEFT RIGHT --energy-atol-ev 1e-10 --projector-atol 1e-8
```
