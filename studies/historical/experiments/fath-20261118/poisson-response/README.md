# Однократный отклик периодического Пуассона при 54 мВ

Для шести сохранённых плотностей электронная энергия Хартри имеет размах **1,82–2,09 мэВ** и среднеквадратичное отклонение **0,59–0,69 мэВ**. Это 3,36–3,88% от энергии падения 54 мэВ за период. Каждый вход получен с фиксированным нулевым Хартри и имеет статус unresolved. Измеренный отклик характеризует электростатический масштаб при этих плотностях. Он не использовался в Dyson, SCBA или для расчёта нового тока.

## Профили

| Сохранённое состояние | Карты | Размах, мэВ | σ, мэВ |
| --- | ---: | ---: | ---: |
| Native PzP7, исходная сетка | 128 | 2,09319 | 0,68656 |
| Compact PzP7 | 64 | 2,06544 | 0,68064 |
| Compact bounded POD7 | 64 | 1,86076 | 0,60370 |
| Compact PzP7, расширенный верхний край | 64 | 2,06556 | 0,68068 |
| Wide unbounded POD9 | 96 | 1,81705 | 0,59149 |
| Native PzP7, промежуточный checkpoint продолжения | 128 | 2,06874 | 0,67885 |

У всех профилей минимум электронной энергии лежит в донорном сегменте, на 35,22–36,44 нм. Максимум wide POD9 расположен на 8,39 нм, в остальных случаях на 16,62–17,53 нм. Максимум абсолютной и RMS разности между исходным native и его продолжением равен 0,0251 и 0,0140 мэВ. У пары compact PzP7 и bounded POD7 на одинаковой сетке эта разность равна 0,1277 и 0,0815 мэВ. Расширение верхнего края при фиксированном compact PzP7 меняет профиль не более чем на 6,8×10⁻⁵ мэВ. Сравнение исходного native с wide POD9 даёт 0,7509 мэВ по максимуму и 0,4256 мэВ по RMS при одновременном изменении базиса, энергетической и импульсной сеток.

Размах отклика превышает одночастичные допуски 0,10–0,50 мэВ и ошибки low-energy hold-out для POD9 (0,17–0,28 мэВ). Он меньше наблюдавшихся многомэВных ошибок проекции PzP7. Это сравнение масштабов. Размах потенциала не задаёт сдвиг отдельного уровня или расщепления. ## Входные данные и проверка знака

Пять терминальных матриц листовой плотности взяты из малых `terminal-observables.toml`. Профиль восстанавливался по всем элементам матрицы как вещественная диагональ ΦPΦ†, делённая на физический шаг по z. Φ, сетка, εᵣ(z) и нормированный донорный профиль взяты из того же `model.h5`. Для промежуточного checkpoint, где такой малой матрицы нет, считывался только Gˡ по отдельным k-срезам и выполнялось исходное интегрирование e171. Вся пространственная таблица содержит 144 узла на вариант. Все εᵣ=12,9.

Нативный e171 решает −∂z(εᵣ∂zUᴴ)=e²(n−Nᴰ)/ε₀ для электронной энергии в джоулях. Положительный избыток доноров снижает электронную энергию в своей области. Периодическая калибровка задаёт среднее Uᴴ по ячейке равным нулю. Исходный подписанный дисбаланс считается как интеграл Nᴰ−n. Бордированная система удаляет постоянную компоненту правой части для решения периодического уравнения. Плотности в исходном состоянии остаются прежними.

Донорный листовой интеграл равен 3×10¹⁰ см⁻². Исходный остаток не превышает 3,62×10⁻⁴ см⁻² по модулю (1,21×10⁻¹⁴ относительно донора). Остаток после удаления постоянной компоненты не превышает 1,86×10⁻⁶ см⁻². Нативная невязка относительно исходной правой части не превышает 1,43×10⁻¹³. Независимое интегрирование периодических гранных потоков в СИ согласуется с e171 в пределах 5,8×10⁻¹⁵ мэВ, а FFT с дискретным символом лапласиана согласуется с гранным интегралом в пределах 1,7×10⁻¹⁵ мэВ. [Уравнение e171](https://github.com/Afonenko-QCL-NEGF/QCLNEGF.jl/blob/e171caa60cce676c6c4238dd671e7c527f2bd977/src/numerics/reference/poisson.jl) · [Хэши источников](density-sources.toml)

## Воспроизведение

Публичные `density-input.csv` и `density-sources.toml` содержат готовые пространственные профили, единицы, нативный ответ и его происхождение. Для повторения независимой проверки и пересоздания итоговых CSV нужны Python 3.11+ и NumPy.

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python poisson-response/response.py
```

С локальными исходными артефактами транспорта можно повторить извлечение n(z) и нативный решатель через Julia 1.13.4, зафиксированное окружение e171 и HDF5. По умолчанию скрипт читает соседний каталог `transport`. Путь к иному каталогу можно передать последним аргументом. Извлечение заняло 9,9 с при пиковом RSS 433 МиБ на одном CPU. Независимый повтор занял 0,25 с и 42 МиБ.

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 julia --startup-file=no --threads=1 --heap-size-hint=220M --project=/path/to/pinned-environment poisson-response/extract_and_native.jl
```
