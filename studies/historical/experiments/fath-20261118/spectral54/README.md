# Спектральная сумма при 54 мВ на сохранённом ретардированном срезе

На исходной native54-03 и на контрольной точке 256 свежих карт продолжения уточнение квадратуры уменьшает невязку спектральной суммы примерно вдвое. Точный интеграл выбранного интерполянта на прежнем окне даёт **0,00562 и 0,00561** при допуске e171 **0,001**. Остаток почти полностью состоит из превышения спектрального веса над единицей. Это наблюдение ограничено одним исходно худшим импульсом k=0,375 нм⁻¹, двумя сохранёнными состояниями и интерполяцией внутри [−400, 560] мэВ.

## Воспроизведение исходного среза

В каждом состоянии прочитан только один импульс для Gᴿ, A и Σᴿ пяти собственных каналов и суммарного embedding. Локальный h(k) восстановлен из сохранённых H₀, Φ, массового профиля и Z со штатным знаком −FZ. Вход Uᴴ=0, рабочая η=0. Независимый Dyson replay согласуется с сохранённым Gᴿ до 4,1×10⁻¹⁴ по относительной норме Фробениуса, с A до 3,5×10⁻¹⁴. Представления i(Gᴿ−Gᴿ†) и Gᴿ i(Σᴿ−Σᴿ†) Gᴿ† совпадают до 9,8×10⁻¹⁶. Минимальное собственное значение уширения на исходных узлах выше -1,3×10⁻¹⁵ мэВ.

Сумма e171 использует S=Σₑ wₑAₑ/(2π) и r_sum=‖S−I‖F/√7 в безразмерных величинах e171, без усреднения по импульсу. Внутри каждой исходной ячейки Σᴿ линейно интерполируется вместе с энергетическим членом в операторе Dyson. Положительность уширения при этом сохраняется с исходной погрешностью округления. Для D(t)=D₀+t(D₁−D₀) интеграл D(t)⁻¹ вычислен через матричную функцию log(1+X)/X, где X=D₀⁻¹(D₁−D₀). Независимая 24-точечная квадратура Гаусса на каждой исходной ячейке совпадает с этим интегралом до 6,6×10⁻¹² в норме суммы. Ни один метод не обращается за пределы окна. [Метрика e171](https://github.com/Afonenko-QCL-NEGF/QCLNEGF.jl/blob/e171caa60cce676c6c4238dd671e7c527f2bd977/src/numerics/reference/validation.jl#L105)

Наибольшие отдельные ошибки исходной трапеции находятся у 84,7, 99,7, 87,7 и 375,5 мэВ. Шкалы мнимой части локальных корней линейного оператора Dyson у 84,57 и 99,59 мэВ составляют 0,13 и 0,11 мэВ. ## Энергия и знак остатка

После устранения ошибки квадратуры спектр матрицы S простирается от 0,999831 до 1,012262 для native54-03 и от 0,999831 до 1,012295 для checkpoint-0256. Наибольший избыток даёт 68–69% квадрата оставшейся нормы. Для исходного состояния положительная часть даёт нормированную норму 0,0056152, отрицательная — 6,39×10⁻⁵.

Главное избыточное направление имеет квадрат перекрытия 0,9987 с верхним собственным вектором локального h(k) при 360,633 мэВ. Его спектральный максимум по сохранённым узлам лежит на 375,2 мэВ, а медиана накопленного веса — на 373,93 мэВ. К 429,2 мэВ накопленный вес в этом направлении уже превышает единицу. Участок 300–560 мэВ содержит 0,9514–0,9515 веса, а крайние верхние 36,8 мэВ — лишь 7,03×10⁻⁵. Нижний край даёт нулевой вес с точностью округления. Добавление внешнего положительного спектрального веса при сохранённом внутреннем спектре может только увеличить интеграл в этом направлении.

В контрольных состояниях доля занятых состояний вне доверенного окна −140…300 мэВ уменьшилась с 2,723% до 0,332%. Полная Σᴿ на выбранном срезе изменилась на 0,367% по относительной норме. Точные матричные суммы отличаются на 5,14×10⁻⁵ по норме e171, а квадрат перекрытия главного избыточного направления равен 0,99999982. Поэтому уменьшение занятого хвоста в этих двух сохранениях не сопровождалось заметным изменением спектральной суммы.

Квадратура на шаге 0,20 мэВ заметно влияет на измеренную невязку. Простой пересчёт квадратуры при зафиксированной Σᴿ оставляет остаток выше порога. Проверка не определяет, как ведут себя самоэнергия и спектральный избыток после новой самосогласованной сборки, не измеряет новую худшую точку по всем k и не оценивает спектр за окном. Неотрицательное уширение на действительной оси само по себе не проверяет глобальную аналитичность интерполированной самоэнергии. [Скалярные свидетельства](diagnostics.json)

## Повтор

Нужны Python 3.11+, NumPy, `h5dump` и локальные архивные состояния `native54-03` и `native54-long-alpha02/checkpoint-0256` в каталоге транспорта. Скрипт сверяет записанные идентификаторы и SHA модели, отдельно подписывает прочитанные блоки. Полные SHA состояний перенесены из проверенных транспортных сводок, хэши заново по большим файлам не вычислялись. Скрипт не сохраняет матрицы. Последний повтор использовал один CPU, 98 МиБ RSS и 6,6 с. Новые итерации SCBA не выполнялись.

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python spectral54/frozen.py --transport /path/to/transport
```
