В причинных используется главное значение для ReΣ каждого канала из его уширения, привязка 5,8 мэВ, линейный спад уширения на одной крайней ячейке за окном и нуль дальше. Полости пересчитаны на сдвинутых энергиях с прежними связями. На общих узлах локальные Σ скопированы, на новых интерполированы. Во всех строках одна парная нормировка по узлам и ноль смешиваний. rΣ и rK — относительные нормы Фробениуса без весов на сетке каждой строки. rΣ берётся относительно свежих Σ как максимум по пяти каналам, двум границам, их сумме и компонентам R, <, >. rK сравнивает входное G< с результатом уравнения Келдыша при входном Gᴿ и свежей Σ<. Спектральный дефект — ‖W−I‖F/√7, где W есть энергетический интеграл A/(2π) для каждого k. Межузловые числа используют аффинный интерполянт обратного Gᴿ. Образ получен ещё одной оценкой Дайсона на свежих Σ.
