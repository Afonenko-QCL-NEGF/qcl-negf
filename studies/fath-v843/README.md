## Пространственное уравнение

Пусть $S=W^\dagger W$, $D=ES-H-\Sigma^R$ и $L=G^<$. Из $DL=\Sigma^<G^A$
получаем $EL-S^{-1}HL-S^{-1}\Sigma^R L=S^{-1}\Sigma^<G^A$.
Складываем с сопряжённым уравнением. Член $EL$ сокращается, поскольку
$L^\dagger=-L$. При $G^A=(G^R)^\dagger$ и
$(\Sigma^<)^\dagger=-\Sigma^<$ остаётся

$$
 S^{-1}HL+(S^{-1}HL)^\dagger =
 \sum_a \left[Y_a + Y_a^\dagger\right],\qquad
 Y_a=-S^{-1}\Sigma_a^R L+G^R\Sigma_a^< S^{-1}.
$$

Здесь $a$ пробегает пять каналов, собранных через все сдвинутые периоды.
В выражении предполагаются один и тот же исходный $G$ и те же источники,
которые использовались в его уравнении. При подстановке свежих источников
на прежнем $G$ остаётся измеряемая кинетическая невязка. Каждый член
переносится на физические узлы центрального периода через $W\cdot W^\dagger$.
Это даёт вклад в приращение тока по сечениям. Ток через физическую связь
считается из $2t_{j,j+1}\operatorname{Re}G^<_{j+1,j}$. Разность между его
дивергенцией и поднятым модовым коммутатором показывает влияние проекции.
Оба шва ориентированы вдоль +z. При представлении наружу левый шов меняет знак.

Энергетическая и радиальная меры $w_E$, $w_k\,g_s/(2\pi)$ одинаковы для
всех вкладов. Сырой заряд измеряется до парной нормировки. Для поперечной
энергии первый момент берётся по $H(k)-H(0)$ в той же физической области.
Эквивалентная температура всего слоя равна отношению этого момента к заряду
и $k_B$. Усреднение температуры отдельно по подзонам требует проекторов
на сопоставимые состояния.

## Приёмка

Воспроизводящая команда использует подготовленный Pkg-проект `runner/`,
запечатанный вход связанной цепочки и каталог с разрешённым местом для отчёта.
`WORKERS` задаёт ограничение потоков, BLAS использует один поток.

```sh
julia --project=runner studies/fath-v843/profile_experiment.jl ARCHIVE report.json WORKERS compare-unitary
```

Сравнение включает независимую положительную энергетическую квадратуру, все
физические сечения, поворот мод в том же подпространстве и кинетический остаток
при подстановке свежих источников. Для строгой стационарности требуются три
последовательные свежие проверки $r_\Sigma, r_K, |\lambda-1| < 10^{-8}$ и
спектральный дефект $<10^{-3}$ на всех кольцах. Пространственная ошибка и
численная неопределённость тока сравниваются с
$\max(1\,\mathrm{А/см^2},0{,}01|J|)$. Сходимость и физическая оценка внешней
кривой требуют отдельного сравнения после этого допуска.
