# Исходники радиального входа V843

Эта копия сохраняет исходные файлы подготовителя и относительные пути
модулей. Контрольные суммы записаны в [SHA256SUMS](SHA256SUMS).
Геометрия подаётся явно. Для двух полей один файл
`.build/fath-dupont-next/work/dupont/tail-geometry-q28.h5` содержит два
набора W, Q и гамильтонианов. SHA-256 файла
`aac3fef169377199051d1380bbdecbf978b396d6f0804d2c83da6177c772536a`.
Он входит в сохранённый локальный научный архив.
