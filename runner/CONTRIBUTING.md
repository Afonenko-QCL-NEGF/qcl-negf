# Участие в разработке Runner

Проверяйте затронутое поведение через публичные интерфейсы. Конфигурация
отклоняет неизвестные поля и недопустимые единицы. Сохранённое состояние
содержит научную идентичность, контрольные суммы и данные для точного
возобновления. В проверку включайте повреждённые или несовместимые входы.

Уравнения и типы модели в памяти принадлежат Core. Runner загружает Core
через Julia Pkg. Изменения формата результатов проверяйте совместно с
[analysis](../analysis/README.md). Вердикт кампании исходит из критериев
исследования. Успешный код выхода сообщает о завершении процесса.

Проверки выбирайте по затронутому коду. Команды проекта определены
в [deno.json](deno.json), проверочный маршрут приведён в [README](../README.md).
