# Поля исследовательского задания

Заполняй только существенное; неизвестное отмечай явно.

| Поле | Содержание |
| --- | --- |
| Вопрос и решение | Какая наблюдаемая/механизм исследуется; что изменит ответ |
| Baseline | Прибор, температура, bias, контакты/baths, механизмы, единицы и источники |
| Гипотезы | Конкурирующие объяснения и различающие наблюдения |
| Свидетельства | Точные источники, независимая опора, нужные артефакты |
| Сопоставимость | Что фиксировано, что меняется, какой вывод допустим |
| Критерии | Применимость, нормировка, абсолютный/относительный допуск и основание |
| Полномочия | Разрешённые анализ, изменения, установки, опыты и публикация |
| Ресурсное окно | Общие CPU/RAM, срок, ограничение вывода, сохранение и остановка |
| Выход | Подтверждённое/неподтверждённое, ограничения и следующий различающий шаг |

Число конкретных опытов выбирает исполнитель внутри согласованного окна,
если поручение не задаёт его отдельно. Каждому тяжёлому опыту нужны собственные
конечные пределы; делегирование не увеличивает общий ресурс кампании.

Исход не обязан быть положительным. Остановка: вопрос разрешён в оговорённой
точности; исчерпано окно; нет следующего полезного разрешённого действия;
обнаружена конкретная недоступная зависимость. Сохрани различающие свидетельства.
