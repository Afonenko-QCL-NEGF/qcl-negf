# Контракт исследовательского запроса

Заполнять только существенное; неизвестное отмечать, а не угадывать.

| Поле | Содержание |
| --- | --- |
| Вопрос и решение | Какая наблюдаемая/механизм исследуется; какое решение изменит ответ |
| Физическая постановка | Прибор, температура, bias на период/весь прибор, контакты/периодичность, активные механизмы, единицы |
| Гипотезы | Альтернативы и наблюдения, которые способны их различить |
| Свидетельства | Репозитории/commits, литература/формулы, study/run/attempt, archives/checksums, dataset paths |
| Сопоставимость | Что фиксировано; что меняется; reference и его независимость |
| Приёмка | Наблюдаемые, применимые критерии, абсолютные/относительные допуски с основанием, погрешности |
| Полномочия | Только постановка / анализ данных / изменение / конкретный вычислительный этап |
| Бюджет опыта | Только если планируется: attempts, CPU/RAM/wall time/I/O, stop/resume, предел повторов |
| Выход | Реестр утверждений и доказательств; сохранить/изменить/измерить; следующий шаг |
| Неизвестные | Блокирующие и неблокирующие; что можно сделать уже сейчас |

Пример цели: установить, позволяют ли имеющиеся архивы принять стационарный
транспортный результат при выбранных условиях и что ограничивает доказательность.
Не подменять её требованием обязательно найти ошибку или получить accepted status.

Условия остановки: вопрос разрешён в пределах заявленной точности; данных
недостаточно для различения альтернатив; исчерпан разрешённый бюджет;
следующее действие требует другого этапа. Нужный следующий опыт описать,
но не запускать вместо честного заключения «данных недостаточно».
