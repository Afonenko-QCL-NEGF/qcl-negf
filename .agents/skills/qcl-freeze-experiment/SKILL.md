Начни с границ [архитектуры приложения](../../../docs/architecture.md) и
[контракта Runner](../../../runner/CONTRIBUTING.md). Проследи путь от авторского
входа через публичные операции планирования и исполнения до Python-читателя.

Сверь эквивалентные авторские входы по эффективным физическим величинам,
включая оси точки, размерности, меру и численный метод. Проверь, что релокация
входов и смена числа workers оставляют научную идентичность прежней. Для
контролируемой вариации проверь все отличающиеся листья. Идентифицируй
загруженное дерево Core через Julia Pkg.

Открой результат через независимый читатель. Повреди один проверяемый
отпечаток, вход либо запись именованного выхода и проверь технический отказ.
Отдельно проверь отсутствующее научное наблюдение и штатный отказ по
критерию. Для конкретного теста используй [научные правила](../../../docs/research-workflow.md).
