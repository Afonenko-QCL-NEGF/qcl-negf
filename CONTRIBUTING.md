# Участие в разработке

Изменения физической модели и численных методов вносятся в
[QCLNEGF.jl](https://github.com/Afonenko-QCL-NEGF/QCLNEGF.jl). Здесь находятся
настройка и запуск расчётов, независимое чтение и инфраструктура лаборатории.

Проверяйте изменения через их обычную точку входа. Для Julia выполните
`deno task --cwd runner test`, для независимого читателя используйте команды
из [analysis](analysis/README.md). При изменении формата результата сверьте
старый и новый файлы независимым читателем. Сохраняйте в Git постановку,
итоговые метрики и происхождение данных.
