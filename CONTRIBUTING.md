# Участие в разработке

Физическую модель и численные методы меняйте в
[QCLNEGF.jl](https://github.com/Afonenko-QCL-NEGF/QCLNEGF.jl). Здесь находятся
Runner, независимый читатель, исследования и инфраструктура лаборатории.

Проверяйте изменения через обычную точку входа. Для Runner используйте
`deno task --cwd runner test`, для независимого читателя — команды
из [analysis](analysis/README.md). При изменении формата проверяйте чтение
файла нового производителя, явный отказ на испорченном входе и научные
статусы. Сохраняйте в Git постановку, компактные метрики и происхождение данных.

Для проверки новой ревизии Core обновите Julia-проект Runner штатным Pkg.
Публикуемые Project и Manifest закрепляют принятую ревизию Core.
