Decision candidate: **MkDocs only as static entry hub**, existing Documenter remains owning Julia API/chapter renderer. Pilot does not migrate nine repos or install eight generators. Phase0 fixes owning entry links; phase1 one bounded three-material bundle; phase2 measured source-to-search adapter for cross-owner search only after identity/offline/light gates. If pinned MkDocs compatible environment unavailable, fallback owning links is a completed narrower outcome, not implicit install.

Single-search design: root/docs owns a derived index over explicitly included bound artifacts, with owner/source/anchor in every hit. MkDocs native index covers hub pages; separate adapter needed for Documenter search_index and root/runbook source. Do not independently edit copied scientific prose. Pilot search scope is three selected materials only; full nine-segment index remains partial/not_measured. Adapter/version decision is local needs_design, not a new scientific contract.
