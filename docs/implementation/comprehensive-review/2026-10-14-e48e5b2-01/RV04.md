## Source findings и impact

Observation F04.1: explicit core_api includes underscore helpers, например `_AndersonWorkspace`,
`_C̄`, numerical metadata types. Inference: Core internal structural changes могут затронуть
Runner even without semantic public solve signature change. Это bounded coupling observation,
не требование немедленно перенести код или скрыть imports. Hypothesis о нарушенном public API
не подтверждена: подробный documented expert-interface catalogue ещё надо сопоставить RV19.
Proposal: сохранить numerical ownership, определить expert/private adapter contract по symbols,
impact matrix для changes у owning Core и Runner. LOC не используется как defect criterion.

Observation F04.2: storage observer добавляет :model_capabilities в observables перед сериализацией.
Inference: вызов persistence имеет in-memory annotation effect; standalone observer contract должен
указать это, чтобы immutable numerical-result proposal был обоснован. Отсутствие измеренной
ошибки physics не превращается в false pass и не означает необходимость копировать большие arrays.
Negative case: mover filesystem/HDF5 into Core changes library dependencies; shared numerical
helper into supposedly independent oracle preserves common-error risk.
