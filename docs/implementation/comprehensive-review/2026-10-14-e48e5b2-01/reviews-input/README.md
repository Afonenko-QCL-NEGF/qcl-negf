# Verbatim candidate snapshots

каталога R. Их SHA256 зафиксированы до независимого чтения. Относительные Markdown
ссылки внутри копий сохраняют исходный base directory **R**, не reviews-input/.
Они не переписываются при correction rounds, чтобы не потерять reviewed bytes.
