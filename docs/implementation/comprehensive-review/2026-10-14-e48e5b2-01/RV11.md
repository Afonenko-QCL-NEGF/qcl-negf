## Generic runtime checkpoint distinction

`filesystem_repository.jl::save_runtime_checkpoint!` writes payload temp, hash/bytes→immutable
payload→metadata envelope containing run_id/point_id/generation/attempt→reference. Эта выбранная
функция не вызывает `_sync_artifact_file/_directory` явно; `_immutable_yaml` implementation и
end-to-end application durable contract требуют отдельной проверки. Не наследуем scientific
point commit durability автоматически generic runtime checkpoint. F11.1 — bounded gap, не
наблюдённая потеря данных. `_atomic_replace_file` uses single same-dir jl_fs_rename; no copy/delete
fallback. Atomic namespace replacement не равно physical-media persistence без barriers.
