## Redaction, unknowns и proposals

LOG.exception then generic503. Fixture `test_broker_unavailable_is_not_reported_as_success`
вводит private internal broker address и проверяет absence в response. Inference: response
redaction этой ошибки предусмотрена; full public logging/reverse proxy telemetry sanitization
не установлена. Traceback logging может содержать internal error text и требует policy доступа;
конкретной утечки credential не найдено и не утверждается.

Observation: arbitrary command resource field rejected before submission; bearer/capability
не scientific authority. HTTP success не proof convergence. Source guard default token/env
fail-closed, но live secret lifecycle outside scope.

protected owner/mode, invalid source runtime/Code. Small public synthetic fixture можно строить
без real tokens/server; parent namespace ownership может требовать controlled privileged fixture.

fixture/discovery ticket. Existing exact locator tests сохранять; composite export attempt
semantics отдельно RV07, не считать single-file fix полной archive pinning.
