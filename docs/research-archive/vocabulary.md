# Факторы, механизмы и наблюдаемые

```{qparam} Дискретизация LO
:id: QPAM_LO_DISCRETIZATION

Вес и геометрия квадратуры, азимутальные узлы, интеграл по продольному импульсу и дискретизация энергетических переходов LO. Для каждого опыта указан фактически заменённый элемент.
```

```{qparam} Доля свежего источника при смешивании
:id: QPAM_MIX

Параметр итерации. Подтверждение стационарности использует невязки свежей карты до смешивания.
```

```{qmechanism} Рассеяние на продольных оптических фононах
:id: QM_LO

Полярное LO-рассеяние. Поле `lo_mode: enabled` фиксирует присутствие канала. Связь `targets` означает, что опыт проверял вклад или поведение механизма. Связь `varies` с дискретизацией LO означает численное вмешательство.
```

```{qmechanism} Перераспределение заряда при решении Дайсона и нормировке
:id: QM_DYSON_NORMALIZATION
:depends: QPAM_RADIAL

Решение Дайсона определяет сырой заряд, затем нормировка изменяет вход оператора столкновений. Сравнение на новом G с новой нормировкой относится к совместной замене.
```

```{qobservable} Ток или плотность тока
:id: QO_CURRENT

Скалярный ток, среднее, шов или отдельное сечение с оговорённой конвенцией знака. Полный профиль индексируется отдельно в {need}`QO_JZ`.
```

```{qobservable} Свежая невязка и невязка итерационного шага
:id: QO_RESIDUAL

Для сравнения определений нужны формула, норма, стадия вычисления и факт смешивания. Кинетическая и поканальная невязки указываются отдельно.
```

```{qobservable} Стационарность по протоколу опыта
:id: QO_STATIONARITY

Совместная проверка свежих невязок, сырого заряда, спектрального дефекта и пространственного тока по заданным допускам и числу последовательных подтверждений.
```

```{qobservable} Сырой и нормированный листовой заряд
:id: QO_CHARGE

Наблюдения различают сырой вход после Дайсона, заряд после нормировки, свежий образ и перенесённую плотность.
```
