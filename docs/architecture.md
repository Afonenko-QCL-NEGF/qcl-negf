# Архитектура QCL NEGF

[QCLNEGF.jl](https://github.com/Afonenko-QCL-NEGF/QCLNEGF.jl) содержит размерную
физическую модель, сборку операторов, решатели и расчёт наблюдаемых в памяти.
Проект [runner](../runner/) загружает Core через Julia Pkg. Источник Core указан
в `runner/Project.toml`, разрешённое дерево пакета — в `runner/Manifest.toml`.

Runner считывает авторские входы, строит план и выполняет отдельные расчёты.
Он отвечает за выходные файлы и checkpoint. [analysis](../analysis/) читает
результаты независимо от Julia и содержит независимую реализацию расчёта тока.
[studies](../studies/) содержит конкретные постановки, правила допуска,
графы опытов и опубликованные свидетельства.

[lab](../lab/) описывает размещение и доставку через HTCondor, конфигурацию
машин через Ansible и VM через OpenTofu. Модель, численный метод и научные
критерии задаются самой постановкой. Очередь предоставляет ресурсы и сообщает
статус задания. Для вывода о сходимости и физике используются научные результаты.
