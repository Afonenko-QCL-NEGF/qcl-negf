# Требования следующего релиза

Статус: согласованные пользовательские требования и явно отмеченные
уточнения проекта. Дата: 2026-10-09. Реализация оценивается отдельно в
[review](review.md); наличие требования не означает его выполнение.

Обозначения: **С** — согласовано в беседе; **Н** — последнее поручение
пользователя; **П** — предлагаемый способ уточнить проверяемое поведение.
Статус П требует проектного решения, а не голосования о физической истине.

## Требования, нуждающиеся в точном проектном определении

- «Максимум ресурсов» означает максимум **после** резерва гипервизора,
  storage/control и согласованных минимумов посторонних VM. Это не обещание
  использовать всю физическую RAM каждым одновременно активным процессом.
- Согласовано: CPU-часы для жёсткого бюджета — выделенные Slurm
  CPU × время выполнения allocation, включая простои и неудачи. Ожидание
  очереди не расходует этот бюджет; фактическое CPU-время — другая метрика.
- «Полные результаты» означает полный **сохранённый** набор принятого профиля
  вывода, с перечнем отсутствующих данных; не все возможные промежуточные массивы.
- Discovery определяет адрес/возможности узла, но не предоставляет доверие.
  Доступа к LAN DNS configuration нет: базовый controller endpoint задаётся
  явно при установке. mDNS — опциональное удобство после проверки сети.
- Первый этап S01 согласован: 0 mV/period и 70 K, согласованные thermal baths.
  μ определяется числом электронов и спектром. Численные допуски и бюджет
  устанавливаются из аудита/ограничений до запуска. Следующая ненулевая точка
  имеет отдельную постановку; кривая 200 K не является oracle первой задачи.
- Первое resource admission конкретизируется по ходу реализации после
  обследования диска/ресурсов. До запуска обязательны безопасный envelope
  и конечный бюджет; отсутствие calibration не разрешает угадывать RAM.
- Согласованы отдельные VM с передачей ресурсов и пересборка без старого
  состояния. Размеры RAM/swap, источник адреса controller и доступность
  зависимостей холодного bootstrap остаются измеряемыми/проектными условиями.
